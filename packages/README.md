# packages/ · 共用能力归属

> 当前没有产品代码。首版已确认本地 Web 工作台 + 共用任务核心 + CLI，见[产品依据](../docs/product/product.md)和[正式路线图](../docs/product/roadmap.md)。

本目录承接可被不同入口复用的能力。任务、现场、反馈和复查结果应共用事实，具体包划分由阶段 1–2 的设计与后续 change 决定。
不提前建立空包，不恢复旧 `core / confirm / reduce / replay / cli` 五包承诺；那是封存阶段的划分。

实现时遵守：

- 数据、日志、缓存和临时文件只落产品数据根或用户明确指定的目录；数据根可见，不可写时明确报错。
- 机器输出有版本，日志与结果分开；缺失上下文、未执行和不确定不能显示为通过。
- 用户意见、实际观测、自动检查候选和 Agent 处理结果保留来源，不猜造源码位置。
- UI 与 CLI 复用共用能力，不让 Agent 必须点击工作台完成任务。
- 人类可读文案按[i18n 口径](../i18n/README.md)逐步接入，不在本目录自行复制另一套工程规则。
