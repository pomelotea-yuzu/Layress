# apps/ · 应用入口归属

> 当前没有产品代码。首版主形态为本地 Web 工作台，Agent 通过 CLI 使用共用任务核心，见[产品依据](../docs/product/product.md)。

这里承接应用入口。具体服务、前端及目录划分在阶段 1–2 的细分设计中确定，当前不创建空应用。
Electron / 其他桌面壳与 MCP 由实际需求决定，不作为首版前提；被测 Electron 应用的适配与 Layress 自身是否采用桌面壳是两件事。

实现时，入口与 CLI 共享任务和证据，现场圈画位置绑定采集条件；Agent 回传“已修复”不自动完成用户复核。
产品数据与临时文件遵守[便携存储要求](../AGENTS.md)，界面类结果区分机器检查与人工验收。
