这里承接 Tauri 桌面应用入口。Rust 原生层、TypeScript 前端及具体目录划分在阶段 1 的实现设计中确定，当前不创建空应用。

实现时，入口与 CLI 共享任务和证据，现场圈画位置绑定采集条件；Agent 回传“已修复”不自动完成用户复核。
产品数据与临时文件遵守[便携存储要求](../AGENTS.md)，界面类结果区分机器检查与人工验收。
