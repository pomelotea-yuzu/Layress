# docs/architecture/ · 架构

> 归属说明。这里放已实现或已核实、持续有效的模块边界、数据流、存储与接口机制；当前尚无产品实现。

## 这里放什么

- 后续 `overview.md`：Tauri 桌面工作台、系统 WebView、Rust 原生层、任务核心与 CLI 的实际边界及数据流，包划分以实现为准。
- 机制专题：现场与标记坐标、任务事实、Agent 结果、复查记录、版本与兼容性。
- 存储与便携：数据根解析、缓存和临时文件归属、系统 WebView 会话目录覆盖与数据迁移；逐端核查默认路径，选定 Tauri 不等于已经满足便携承诺。

## 进入门槛

- 未定稿交互放 `docs/product/` 的主题设计；单项未实现方案放对应 `openspec/changes/<name>/design.md`。按[路线图](../product/roadmap.md)登记入口，不预建空文档。
- 已核实的机制可按主题成文，明确适用范围与证据；不把计划写成已有实现。
- 默认中文；对外英文按需逐篇登记，权威性低于源码与归档 change，见[文档地图](../README.md)。
