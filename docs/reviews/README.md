# docs/reviews/ · 实机验收与审阅证据

> 归属说明。这里放**验收记录与审阅证据**：谁在什么版本、什么环境下验了哪些判据、结果是什么。
> 不要求中英成对。

## 入库口径（重要）

- **文字记录入库**：验收清单、判据索引、结论。
- **过程截图默认不入库**：`.gitignore` 已排除 `docs/reviews/**/*.png`。
  证据目录确实要对外展示时，按洁净度口径在 [`.git-hygiene-allowlist`](../../.git-hygiene-allowlist)
  登记 `glob  #  理由`，再 `git add -f`。没有理由的豁免判红。
- 一次验收一个目录：`YYYY-MM-DD-<对象>/`，内含 `README.md`（判据索引）与测量文件（JSON）。
  原始截图放该目录的 `screenshots/`，默认留本地。

## 纪律

- **未执行的项写"未执行"**，不许勾完成，也不许在状态卡里写成已交付。
- 视觉/交互判定归人工：写清是谁看的、看的是哪个构建、窗口尺寸与缩放等条件（不变量 I3）。
- 判据必须能反证：同批记录里包含"已知坏样本应判红"的对照，否则这份验收不能证明工具有效。
- 截图若含真实项目页面内容，默认不外发（不变量 I8；脱敏口径见 [`../knowledge/debt.md`](../knowledge/debt.md)）。
