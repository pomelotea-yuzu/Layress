# invariants.md · 架构与口径不变量

<p><a href="invariants.en.md">English</a> | 简体中文</p>

> 这些条目**不许重开**。每条给出不成立时的后果——没有后果的"原则"只是措辞偏好，那种东西不该写在这里。
> 新增不变量的门槛：已经因为违反它吃过一次可测量的损失，或它是某个产品主张的唯一保障。

| # | 不变量 | 不成立时会发生什么 |
|---|---|---|
| I1 | **候选不等于缺陷**。几何异常只进入候选层，确认层产出三态判定（confirmed / not-a-defect / inconclusive），报告必须保留层的区分 | 报告退化成告警噪音，用户第一次误报后就不再相信任何一条，工具直接失去价值 |
| I2 | **可达性判定以真实命中测试为准**。程序化点击只能用于准备状态，不能用作"能点到"的证据 | 把被遮挡的操作报成可用——这是本产品的反向失效，比漏报更伤信任 |
| I3 | **触发条件四元组完整**：尺寸（宽×高）+ 界面状态 + 字体/缩放 + 语言。缺任一项 ⇒ 标记为不可回放，不许静默补全 | 换一台机器复现不出来，"可回放证据"这个交付物名存实亡 |
| I4 | **来源缺失、损坏或未知状态不得被 UI 猜测补造为可信事实**。宁可显示 unknown | 用户按猜出来的条件去修 bug，改错了地方，且回不来追溯 |
| I5 | **回放不新增真实外部副作用**；重跑必须显式授权并说明副作用与费用 | 一次"只读"的回放把目标应用的表单提交了 |
| I6 | **无需正确截图基线 ≠ 无需规约**。关键操作、准备步骤、可接受滚动、排除范围必须由开发者声明 | 工具开始替用户判定"什么算重要"，误报率与主观性同时失控 |
| I7 | **数据集物理分离**：调规则用的子集与最终评估子集不重叠，评估集不进入规则迭代回路 | 指标随规则上涨但外部项目一个缺陷都发现不了，首验结论作废 |
| I8 | **本地优先**：页面内容、截图、扫描结果默认不出本机。使用远程模型必须显式声明数据流与成本，且**不得静默降级为远程** | 客户界面数据在用户不知情下外发；这是法务级事故，不是隐私口号 |
| I9 | **缩减只有在保持失败的前提下才算完成**：每去掉一个条件都要验证仍能复现，不能为通过而丢弃必要前件 | 产出一个"最小复现"却根本不复现，开发者按它试一次就弃用工具 |
| I10 | **扫描 / 确认 / 缩减 / 回放四模块可独立使用**，且核心检测与报告完整开源 | 免费部分不足以独立完成一件事，开源只剩招牌 |
| I11 | **机器 PASS ≠ 人工通过**：视觉与交互判定归人工复核，未执行的复核单列 | 状态卡显示全绿而实际没人看过一眼，接手人据此继续推进 ⇒ 整段返工 |
| I12 | **不碰 C 盘（便携优先）**：数据、日志、缓存、临时文件写在产品自身目录或用户显式指定目录；**不得**默认写入 `%APPDATA%`／`%LOCALAPPDATA%`／`C:\Users\…`／注册表／`~/Library/Application Support`。安装位置由用户选择，安装器不提权、不改系统 PATH。**写不进就不写**：目标目录不可用时明确报错并要求用户指定，**禁止静默回落到用户目录** | 拷贝目录不能整体迁移、删除目录留残留、企业环境写权限被拒、用户隐私数据散落在系统盘而不自知；"便携"退化成一种营销说法 |
| I13 | **数据目录解析口径唯一且可见**：优先级 `--data-dir` / `LAYRESS_DATA_DIR` > 产品目录下的数据根；解析结果（含是否可写）必须出现在启动输出、日志与报告头部 | 用户无法验证 I12 是否被遵守；同一份产品在两台机器上把证据写到不同位置，回放找不到原始数据 |

## 与前置项目的差异（避免照抄）

- ReBaseAgent 的核心资产是**轨迹与快照的不可变性**（append-only、分叉不改父本）。
  Layress 没有"运行历史"这一层，`I3`/`I9` 承担同样的职责：**证据一旦不完整或缩减过度就作废**。
- ReBaseAgent 的 `I：代理捕获的 key 只在内存` 对应到 Layress 的是 `I8` ——
  外发的是**页面内容**而不是密钥，敏感级别同样高，且截图里可能带姓名、地址、内部路径。
- ReBaseAgent 已采用"便携版业务数据落 exe 旁 `data/`"的口径，Layress **沿用它并推进一步**：
  缓存与临时文件（含 Chromium/Electron 的 `sessionData`、`userData`）同样不得落 C 盘用户目录，
  见 I12 与 [`engineering.md`](engineering.md) 的"存储与便携"。
