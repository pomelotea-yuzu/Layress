- 审美评分、自动修复、任意应用全自动探索、最小 HTML/CSS 自动抽取、全平台全浏览器支持、
  大规模多语言与字体矩阵 —— 调研 §7.2 明确列为**暂缓**。
- `packages/*` 与 `apps/desktop` 目前只有归属说明，没有代码，也没有 `package.json`。
  这是本轮口径（D13），不是半成品。
