## 这里放什么

- 竞品实测记录（**跑过**才写；文档声明的能力不等于已验证效果）
- 论文与研究的机制摘录，以及"能不能落到本产品"的判断
- 数据集来源的外部项目候选与授权核查

## 纪律

- 桌面调研与实机验证必须在文中分列，不许把"读到"写成"测到"。
- 带日期即时效：引用旧调研的结论前先核对是否已被后续证据推翻。
- 证据文件（JSON、抓取记录）与结论文档同目录并排，命名同前缀。
