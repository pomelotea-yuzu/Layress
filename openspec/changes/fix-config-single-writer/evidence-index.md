## 实机记录方法

- 两个实例用同一个桌面二进制和显式绝对 `--data-dir` 启动，核对 PID 与显示的实际根，确保发生真实的重叠运行。用生成的配置和固定本地夹具验证，区别首次写入与无变化复用。
- 实机记录区分目录检测可写、设置配置可写、命令成功及文件已提交。文件或进程证据单独登记，工具层徽标与源码指纹按 I16 核对。对方占锁时的拒绝和释放后的成功须来自同一对运行会话；正常退出和异常退出分别记录。
- 在没有持锁同步点的 GUI 中，若重建请求未实际重叠，标为未覆盖争用；用机器测试单独证明并发窗口，并继续记录 GUI 所见的确认、最终文件和备份。现有存储模块子进程测试单列，不计为真实桌面启动验证。
- 运行日志、截图和配置夹具留在 `.layress/` 或 `artifacts/`。本索引用相对路径或摘要引用证据。默认人工验证平台为 macOS arm64，D30 的打包与 WebView 写盘观测沿发行轮。
