## MODIFIED Requirements

### Requirement: 便携数据根与可写检查

系统 MUST 将截图、元数据、日志、缓存和临时资料放在产品可写目录的数据根或用户显式指定目录，显示解析结果，不默认回落系统用户目录；不可写时明确失败，不以换目录后的运行冒充满足原存储约束。数据根选择优先级 MUST 为 `--data-dir` > `LAYRESS_DATA_DIR` > 可执行文件旁 `.layress/`；有效的命令行或环境变量来源 MUST 使用绝对路径，显式相对路径在解析层拒绝。系统 MUST 独立保存启动解析错误，在状态栏就绪后显示可见红条与解决提示，即使未取得数据根也不得遗漏错误；解析失败和可写检查失败均禁用持久化 / 采集，不创建替代根。

#### Scenario: 数据根可写

- **WHEN** 启动时数据根已解析且可写
- **THEN** 用户可取得实际目录，采集产物归属该根

#### Scenario: 数据根不可写

- **WHEN** 指定或默认产品数据根不可写
- **THEN** 显示已解析的绝对根、不可写原因和可见失败，不回落系统用户目录，不以换目录后的运行冒充满足原存储约束

#### Scenario: 命令行或环境变量给出相对根

- **WHEN** 有效数据根来源为 `--data-dir` 或 `LAYRESS_DATA_DIR` 且值为相对路径
- **THEN** 在解析层返回 `DATA_ROOT_RELATIVE_UNSUPPORTED`，状态栏就绪后显示红条及改用绝对路径的提示；不依赖存在 DataRoot 或启动事件被订阅，持久化 / 采集均禁用且无替代根

#### Scenario: 命令行覆盖环境变量

- **WHEN** 命令行提供有效绝对根，环境变量同时提供另一个值（包括相对路径）
- **THEN** 只校验并使用高优先级命令行值，不因被覆盖的环境变量另行失败；数据根来源和绝对路径可见
