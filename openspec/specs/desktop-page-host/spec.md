# desktop-page-host Specification

## Purpose
在单个 Tauri 原生主窗口内承载本地可信工具界面与被测网页：工具层提供 HTTP(S) 导航、基础视口设定与操作入口，被测页面运行在无任何原生命令能力的隔离 WebView 中。该能力负责"把一个真实页面放进工作区并取得可信现场"——仅含被测页面的真实截图、版本化采集元数据、原图坐标体系与原地静态预览，以及便携数据根（不写系统用户目录）与本次运行的资源归属。它不涵盖反馈任务管理、设备预设库、持久会话、Agent CLI / MCP 与跨平台发行；WebView 写盘观测归发行轮（D30）。首轮验证平台为 macOS arm64（系统 WKWebView），其他平台接入前不得宣称已支持。

## Requirements

### Requirement: 单窗口承载与原生权限隔离

系统 MUST 使用 Tauri，在一个顶层主窗口中承载本地工具界面与隔离被测页面。被测网页不得获得 Tauri 原生命令、任意文件或进程访问能力。

#### Scenario: 在主窗口操作普通页面

- **WHEN** 用户打开已启动的普通本地 HTTP(S) 页面
- **THEN** 页面在主窗口内可点击、输入、滚动和打开页面内弹窗，工具入口仍可使用，无需额外浏览器窗口

#### Scenario: 被测页面尝试越过权限边界

- **WHEN** 被测页面尝试调用工具的原生命令或访问本机文件 / 进程
- **THEN** 请求被拒绝，不能因为页面在应用内加载就取得工具权限

### Requirement: 导航与失败表达

系统 MUST 提供基础 HTTP(S) 地址导航与刷新，明确加载、失败和不支持操作；不得隐式执行危险 scheme 或开启不受控外部入口。

#### Scenario: 用户打开无效地址

- **WHEN** 地址无效、scheme 不受支持或目标不可达
- **THEN** 系统明确拒绝或显示失败，不把旧页面描述为新地址加载成功

#### Scenario: 页面请求额外入口

- **WHEN** 页面请求未支持的新窗口、下载或原生设备权限
- **THEN** 请求受到明确处理，不静默创建额外顶层窗口、写入默认下载目录或授予设备权限

### Requirement: 实际视口与引擎可核对

系统 MUST 支持基础宽高设置，记录或显示实际视口和 WebView 引擎，区分窗口大小、页面视口、DPR、截图像素与展示比例。未验证的模拟条件不得声称支持。

#### Scenario: 两个基础尺寸

- **WHEN** 用户依次设置两个支持的尺寸并打开样例
- **THEN** 页面实际视口可核对，截图条件对应本次页面；尺寸预设不被显示为真机验证

#### Scenario: 工具布局影响可用区域

- **WHEN** 调整应用窗口或工具区域使已选页面尺寸无法完整显示
- **THEN** 系统保留实际视口并明确处理显示限制，不能静默改宽高后仍显示原配置

### Requirement: 绑定当前页面的真实采集

系统 MUST 采集仅含被测页面的真实画面，为每次采集分配标识，保存有版本的页面身份、URL、采集时间、实际视口、图片尺寸和可取得的其他条件。

#### Scenario: 成功采集当前页面

- **WHEN** 当前页面有效且采集成功
- **THEN** 图片不含工具层或其他应用，元数据对应本次页面与条件，缺失信息明确标注

#### Scenario: 采集期间页面发生切换

- **WHEN** 采集期间发生导航、关闭或新请求替代旧请求，使原结果不能可靠归属当前页面
- **THEN** 结果被标为失效 / 取消并可重试，不能将旧图绑定到新页面

#### Scenario: 采集失败而存在旧图

- **WHEN** 本次采集失败且已有上一张图片
- **THEN** 明确显示本次失败，旧图仅作为旧现场，不能显示本次采集成功

### Requirement: 原地静态预览与坐标验证

系统 MUST 在同一工作区显示采集后的静态画面，支持一个临时矩形验证原图坐标，并能够返回同一个被测页面会话；静态预览不得被称为业务暂停。

#### Scenario: 不同展示比例下验证矩形

- **WHEN** 在原始比例和适应区域两种展示下标记已知页面位置
- **THEN** 矩形仍对应同一原图区域，坐标不会把展示缩放重复计算

#### Scenario: 从预览返回页面

- **WHEN** 用户结束预览返回操作页面
- **THEN** 原 WebView 未因工具切换被销毁或重载，未主动清空输入和弹窗；持续运行引起的页面变化不被伪装成截图仍实时有效

### Requirement: 便携数据根与可写检查

系统 MUST 将截图、元数据、日志、缓存和临时资料放在产品可写目录的数据根或用户显式指定目录，显示解析结果，不默认回落系统用户目录；不可写时明确失败，不以换目录后的运行冒充满足原存储约束。

#### Scenario: 数据根可写

- **WHEN** 启动时数据根已解析且可写
- **THEN** 用户可取得实际目录，采集产物归属该根

#### Scenario: 数据根不可写

- **WHEN** 指定或默认产品数据根不可写
- **THEN** 明确报错且不回落系统用户目录，不以换目录后的运行冒充满足原存储约束

### Requirement: 生命周期与交付诚实性

系统 MUST 在退出时取消本次未完成采集并释放资源，分别记录机器、人工与未执行结果；首轮 macOS 验证不得扩写成跨平台支持。

#### Scenario: 有采集进行时退出

- **WHEN** 用户关闭应用
- **THEN** 待完成操作被取消，本次资源释放，不误删数据根外文件，重新启动不依赖遗留后台进程

#### Scenario: 尚未执行的验证

- **WHEN** 整理 change 证据与限制
- **THEN** Windows / Linux、真实移动设备、人工未检查项和受环境阻塞的项目单列，不因文档 / 类型检查通过而勾为完成
